LISTA DE PRESENTES — VERSÃO DEFINITIVA (BASE)

Inclui:
- lista completa de presentes;
- categorias;
- busca;
- cadastro do nome;
- reserva do item;
- layout responsivo para celular.

IMPORTANTE:
Este pacote é a versão frontend completa, mas uma reserva realmente compartilhada entre todos os convidados precisa de um banco de dados online.
A versão entregue usa localStorage como fallback de demonstração.

Para publicar a versão multiusuário real, conecte as funções de reserva a Supabase/Firebase ou outro backend com operação atômica/transaction, evitando que dois convidados reservem o mesmo item simultaneamente.

Também é recomendável adicionar um painel administrativo protegido por senha para os noivos.
